# Test Data Manager

A lightweight and flexible solution for managing, generating, and validating test data across projects. Designed to simplify QA workflows and accelerate automation testing.

## 🚀 Features
- **Data Generation**: Create synthetic test data with customizable rules.
- **Data Validation**: Ensure consistency and accuracy across datasets.
- **Integration Ready**: Works with CI/CD pipelines and popular test frameworks.
- **Scalable**: Supports small projects to enterprise-level test environments.

## 📦 Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/ankurishan/Test-Data-manager.git
cd Test-Data-manager
pip install -r requirements.txt

🛠 Usage
Run the application:
streamlit run app.py

Stop the app with:
Ctrl + C

📂 Project Structure
Test-Data-manager/
│── app.py              # Streamlit app entry point
│── data/               # Sample datasets
│── modules/            # Core logic and utilities
│── tests/              # Unit and integration tests
│── requirements.txt    # Dependencies

💡 Use Cases
1. QA Automation: Generate test data for automated test suites to reduce manual effort.
2. Data Pipeline Validation: Feed synthetic datasets into ETL pipelines to check stability and accuracy.
3. Performance Testing: Stress-test applications with large volumes of realistic data.
4. Compliance Checks: Create anonymized datasets for GDPR/ISO compliance testing.
5.Rapid Prototyping: Quickly spin up mock data for demos, POCs, and hackathons.
